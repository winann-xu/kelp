- 技术规范：[`AGENT.md`](AGENT.md)

## 一句话架构

```
两站点内网 ── EasyTier ── 公网节点 47.116.73.216 ── 手机/第三方设备
              （常态 P2P 直连，节点仅信令与兜底，因为 ECS 按流量计费）
```

## 状态

M0 ✅ / M1 ✅ / M2 ✅ 完成：三个节点（上海 hub + 家里 50.9 + 飞牛 NAS）全部 P2P 直连，两个站点网段双向穿透，跨站点速率基线 17.6–18.1 Mbps，只读面板覆盖 3 台设备。下一步 M3 手机接入。

只读面板：`https://47.116.73.216:18080`（自签证书，浏览器需接受一次；口令见 `~/.config/kelp/kelp.env`，不入库）。
